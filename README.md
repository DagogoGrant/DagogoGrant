## Profile

I am an AI engineer and AI Engineering master's student building systems across machine learning, deep learning, reinforcement learning, computer vision, LLM applications, retrieval, agents, and production automation.

My work sits where models meet software: data pipelines, evaluation, APIs, real-time interfaces, monitoring, and debugging. I care about fundamentals, not tool collecting.

## Selected Systems

- [Machine learning library from scratch](https://github.com/DagogoGrant/ml-algorithms-from-scratch): NumPy implementations of regression, logistic regression, SVMs, decision trees, random forests, K-Means, Naive Bayes, MLPs, CNNs, preprocessing, validation, and evaluation pipelines.
- [Few-shot object detection system](https://github.com/DagogoGrant/AI-Object-Detection-System-with-Few-Shot-Learning): SAM + ResNet-50 visual few-shot learning with generated training images, API endpoints, model feedback, health checks, Prometheus, Grafana, Docker, and a React/TypeScript frontend.
- [Multi-agent debate arena](https://github.com/DagogoGrant/multi-agent-debate-arena): React + FastAPI system with role-based LLM agents, web grounding, LiteLLM provider routing, live fact-checking, confidence visualizations, and streaming backend architecture.
- [ShadowBoxer AI](https://github.com/DagogoGrant/ShadowBoxer-AI): real-time computer vision boxing game using MediaPipe, KNN movement classification, linear regression motion forecasting, and a Q-learning opponent.
- [Pose and gesture AI interfaces](https://github.com/DagogoGrant/Dino-Game-Pose-Controller): real-time body/hand tracking projects for game control, dance imitation, steering, scoring, and low-latency automation.
- [Java software analysis tools](https://github.com/DagogoGrant/Static-and-Dynamic-Program-Slicing-for-Java): static/dynamic slicing, control/data-flow graphs, bytecode analysis, abstract interpretation, interprocedural sign analysis, testing, and CLI tooling.
- [Visual analytics dashboard](https://github.com/DagogoGrant/scrap-alchemist-visual-analytics): D3 dashboard for recycled aluminium alloy discovery with linked filtering, t-SNE/PCA projections, candidate analysis, and performance-composition exploration.

## Engineering Range

- Classical ML: classification, regression, clustering, feature engineering, cross-validation, error analysis.
- Deep learning: MLPs, CNNs, representation learning, training loops, vision pipelines.
- Reinforcement learning: agents, states, actions, rewards, policies, exploration, adaptive behavior.
- LLM systems: prompt design, context engineering, tool calling, structured outputs, agent orchestration.
- Retrieval/RAG: embeddings, vector search, grounding, reranking patterns, retrieval failure analysis.
- Production AI: FastAPI, REST APIs, Docker, monitoring, metrics, CI/CD, debugging, guardrails.
- Software analysis: ASTs, bytecode, graphs, abstract interpretation, static and dynamic analysis.
